화면·팝업 51개 · 요소 420개

## 번호 읽는 법

```
P06-B21
│   │└─ 21번째 버튼
└───┴── P06 = 실현 강도 선택 화면
```

| 접두 | 뜻 |
|---|---|
| `P` | 화면 |
| `M` | 팝업 |
| `A` | 토스트 |
| `B` | 버튼 |
| `F` | 입력 |
| `C` | 카드 |
| `T` | 탭 |
| `N` | 내비 |
| `L` | 리스트 |
| `G` | 차트 |
| `S` | 상태 |

컨테이너(`P` 화면 · `M` 팝업 · `A` 토스트)는 앱 전체에서 유일한 번호이고,
그 안의 요소는 소속 화면 안에서만 번호가 매겨집니다. 항상 두 마디(`P06-B21`)이고 세 마디는 없습니다.
리스트 행처럼 개수가 변하는 것은 화면이 `#1`, `#2` 를 덧붙입니다 — 목록에는 대표 번호만 있습니다.
