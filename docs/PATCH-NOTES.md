# Mybody 패치노트

내부 테스터용. 플레이 내부 테스트 · TestFlight `my` 그룹에 같은 판이 올라갑니다.

## 0.2.20 (347) — 2026-09-28

**★ 계정 사이 기록 섞임 고침(피드백 52).** 한 폰에서 로그아웃하고 다른 계정으로 가입 · 로그인하면 앞 계정의 기록이 그대로 뜨고, 새 계정의 서버 사본 · 주간 요약으로 올라가던 문제.
- 폰의 기록에 주인(계정)을 적습니다. 로그아웃하면 그 계정의 기록을 폰 안에 따로 보관하고 화면은 비웁니다 — 다시 로그인하면 돌아옵니다. 로그아웃 전에 못 보낸 변경은 먼저 그 계정으로 보내 봅니다.
- 다른 계정으로 들어오면 절대 합치지 않고 빈 기록에서 시작합니다(온보딩 · 인사도 새로). 로그인 없이 쓴 기록만 「이 계정에 합칠까요?」 를 묻습니다. 누구 것인지 모르는 기록이면 「다른 계정의 기록일 수 있어요」 를 붙이고 [합치지 않기]를 강조합니다.
- 동기화 · 주간 요약 · 못 보낸 일은 기록의 주인과 지금 로그인이 같을 때만 나갑니다. 서버도 주인이 다른 사본 · 요약은 거절합니다(409).
- 첫 화면에서 가입할 때 복구 코드 창이 안 뜰 수 있던 문제도 같이 고침.
- 노트북 도구 `tools/find-mixed-accounts.js` — 이미 섞인 계정 쌍을 찾아 줍니다(읽기 전용).

**운동 「저장 안 함」(49).** 헬스 · 유산소 · 맨몸 종료 화면에 「저장 안 함」 — 한 번 누르면 기록 없이 닫히고 「기록하지 않았어요」.

**추이 빈 화면(51).** 「인바디를 올리고 확인해보세요!」 + 「인바디 올리기」 · 「인바디 없이 시작」. 측정이 한 번뿐이면 「첫 측정이에요 — 4주 뒤 다시 재면 변화가 보여요」.

**목표 — 체성분으로 정하기(53).** 「마감 (선택)」 카드를 없앴습니다(기간은 다음 화면에서). 화면에 안 보이는 옛 마감이 모드를 바꾸지 않습니다.

**업데이트 안내 기준(50).** TestFlight 안내는 friends(공개 링크) 승인판, 플레이 안내는 비공개 테스트 게시판 기준 — 내부 테스트에만 올린 판은 안내하지 않습니다.

**운영자.** 설정 → 도움말 「가입자 목록」(아이디 · 이름 · 가입일, 누르면 아이디 복사). 컴퓨터 브라우저로 보는 의견함 `<서버>/inbox`(운영자 로그인).

**서버**: 가입자 목록 API · 컴퓨터 의견함 페이지 · 주인이 다른 기록 거절. 서버 업데이트가 필요합니다.

## 0.2.19 (333) — 2026-09-28

**의견함.** 운영자(의견 알림을 받는 계정)로 로그인하면 설정 → 도움말 맨 위에 「의견함」 — 안 읽은 수, 최신순 목록(시간 · 보낸 이 또는 익명 · 판 · 기종 · 화면 · 글 · 캡처), 자세히(캡처 크게 · 확대), 열면 읽음, 지우기. 「새 의견이 왔어요」 알림을 누르면 바로 열립니다. 서버가 매번 운영자인지 확인합니다.

**초대 링크면 바로 친구(피드백 48).** 링크로 들어온 요청은 수락을 기다리지 않고 곧 친구가 됩니다(공유 기본값은 수락과 같게). 거절 · 끊기 · 차단했던 사람은 링크로도 예전처럼 요청만 갑니다. 코드를 손으로 넣으면 요청 → 수락 그대로. 코드 주인에게는 「새 친구가 생겼어요」.

**설정의 크롬 알림 정리(피드백 47).** 「크롬(웹) 알림 끄기」 를 뺐습니다. 앱 알림이 등록되면 예전 크롬 알림 구독을 계정마다 한 번 조용히 지웁니다.

**말풍선(피드백 46).** 꾹 누르기 0.5초 → 0.35초.

**서버**: 의견함 API · 초대 링크 즉시 친구 · 새 친구 알림 문구. 서버 업데이트가 필요합니다.

## 0.2.18 (325) — 2026-09-28

**친구 초대 링크(피드백 43~45).** 공유 문구에는 링크 하나(`…/i/<코드>`)와 코드만 — 받는 사람의 기기에 맞춰 안내합니다.
- 앱이 있으면: 링크를 누르면 앱이 바로 열리고 친구 요청이 자동으로 갑니다(안드로이드 App Links · 아이폰 Universal Links, 로그인 전이면 로그인 뒤에).
- 앱이 없으면: 테스트 기간에는 아이폰 → TestFlight, 안드로이드 → ① 구글 그룹 가입 ② 테스트 참여 ③ 플레이에서 설치. 출시 뒤에는 앱스토어 · 플레이.
- 카카오톡 안에서 누르면 기본 브라우저로 넘겨 앱이 열리게 합니다. 설치 뒤에는 플레이 설치 정보나 복사된 초대 문구로 「초대 코드 ○○ 로 친구 요청할까요?」 한 번.
- 착지 페이지는 코드가 누구 것인지 찾지 않고 이름도 보이지 않습니다.
- 친구 탭 「친구 추가」: 위에 내 코드(누르면 복사) · [보내기], 아래 친구 코드. 코드는 영문 · 숫자 8자(예: K7M2QX9D) — 예전 예시 「ab12cd」 가 틀렸습니다.

**의견 말풍선(피드백 42).** 꾹 눌러 들어 올려 화면 가장자리 어디로든 옮기고, 들어 올리면 아래 가운데 X 가 나와 끌어다 놓으면 치웁니다(테스트 기간에는 「테스트 기간에는 없앨 수 없어요」). 처음 자리는 홈 「인바디」 버튼 바로 위. 설정 → 도움말 「의견 버튼 보이기」(테스트 기간엔 켜진 채 잠금).

**그 밖에** 인사 첫 쪽 「의견은 화면 옆 말풍선으로!」(41) · 계정 삭제 안내에 「계정은 두고 기록만 지우기」.

**서버**: 초대 착지 페이지 · 앱 링크 파일(/.well-known) · 테스트 기간 스위치(`app-version --testing=on|off`). 서버 업데이트가 필요합니다.

## 0.2.17 (314) — 2026-09-27

**인바디 없이 시작.** 홈 빈 화면(과 업로드 화면)의 「인바디 없이 시작」 — 체중만 넣으면 성별 · 나이 · 키(첫 설정 값)로 체성분을 추정해 바로 목표 · 플랜을 세웁니다.
- 체지방률 Gallagher 2000 · 골격근 Lee 2000(둘 다 아시아인 항), 제지방 = 체중 − 체지방, 기초대사량 370 + 21.6 × 제지방. 오차 체지방률 ±5%p · 골격근 ±3kg.
- 추정 숫자에는 「추정」 표시, 그래프는 추정과 실측을 잇지 않고, 친구에게는 몸 숫자로 안 나갑니다.
- 나중에 인바디를 넣으면 추정 기록을 지우고, 추정으로 세운 플랜을 실측 기준으로 다시 맞춥니다(목표 체중 · 골격근 변화량 · 강도 · 마감 유지). 홈에 「실측으로 바꿨어요 · 골격근 35.7 → 38.0kg」 카드가 한 번.

**의견 보내기.** 모든 화면 오른쪽 가장자리의 말풍선 — 누르면 지금 화면이 붙은 채로 시트가 열립니다. 글은 선택, 갤러리 사진도 3장까지(위치 정보는 지우고 보냄). 끌어서 옮기거나 길게 눌러 숨길 수 있고, 설정 → 도움말에서 다시 켭니다. 로그인하지 않아도 보낼 수 있습니다.

**테스터 인사.** 처음 한 번(기존 사용자도 업데이트 뒤 한 번): 인사 · 앱 안내 4단계 · 내 친구 코드(복사 · 카톡 등으로 보내기) · 친구 코드 넣고 바로 요청. 설정 → 도움말 「앱 안내 다시 보기」.

**서버**: 의견 저장(계정 삭제 때 같이 삭제, 1년 뒤 자동 삭제) · 초대 설치 링크 · 새 의견 알림. 서버 업데이트가 필요합니다.

## 0.2.16 (307) — 2026-09-27

**앱 알림이 실제로 켜집니다.** Firebase 설정이 들어간 첫 판입니다 — 로그인하면 (아직 허용하지 않았으면) 알림 허용을 한 번 묻고, 친구의 운동 독촉 · 운동 소식 · 친구 요청이 앱이 꺼져 있어도 앱 알림으로 옵니다. 안드로이드는 바로, 아이폰은 APNs 열쇠를 Firebase 에 올리면(노트북 지시서 28) 앱 업데이트 없이 켜집니다. 그 전에 아이폰으로 못 보내면 서버가 예전처럼 크롬 알림으로 보냅니다.

**헬스 화면 (피드백 38 — "무게 눌러보라는데 좀 비직관적이야")**
- 무게 표시를 눌러 보이는 단추로: 아령 아이콘 · 무게 · ▾. 이름 밑 제 줄에 두어 좁은 폰 · 큰 글자에서도 줄어들지 않습니다.
- 따라 해 보기 2단계: 「무게를 눌러 보세요」 · 「+ · − 로 맞추고 「확인」」. 무게 단추가 세 번 반짝인 뒤 테두리로 남고(동작 줄이기면 반짝임 없이), 「확인」으로 닫아야 다음 단계로 — 그냥 닫으면 「「확인」 을 눌러야 바뀝니다」.

**설정**
- 익숙한 종목은 접어 둡니다(피드백 39) — 「익숙한 종목 N개 ⌄」 를 누르면 펼치고, 끝에 「접기」. 「추가」 는 접힌 채로도 됩니다.
- 로그아웃은 맨 아래 한 줄 단추로 옮겼습니다(피드백 40). 한 번 묻습니다 — 「이 기기와 내 계정의 기록은 그대로 남습니다 — 다시 로그인하면 이어집니다」.

**심사**: 앱스토어 심사와 TestFlight friends 베타 심사는 0.2.15 (298) 로 다시 올려 둔 그대로입니다(이 판으로 바꾸지 않음 — 바꾸면 심사 대기가 처음부터).

## 0.2.15 (298) — 2026-09-26

**앱 알림(진짜 푸시).** 친구의 운동 독촉이 앱이 아니라 크롬(예전 웹 버전의 알림 구독)으로 오던 것을 고칩니다.
- 서버가 안드로이드는 FCM, 아이폰은 FCM → APNs 로 앱에 직접 알림을 보냅니다 — 독촉 · 친구 운동 소식 · 친구 요청. 앱이 꺼져 있어도 옵니다. 누르면 친구 화면.
- 알림 본문은 「친구가 운동하라고 콕 찔렀어요」 같은 일반 문구만(구글 · 애플 서버를 거치므로 이름 · 숫자는 앱을 열어야 보임).
- 앱 알림을 등록한 사람에게는 크롬 웹 알림을 보내지 않습니다. 설정에 「크롬(웹) 알림 끄기」.
- 앱으로 돌아올 때마다 새 독촉을 확인(푸시가 없는 사람을 위한 안전망). 같은 독촉이 두 번 뜨지 않게.
- 로그인한 뒤에만 기기를 등록하고, 로그아웃하면 지웁니다. 개인정보처리방침에 「앱 알림 기기」 항목 추가.

알려진 것: Firebase 설정(노트북 지시서 28 — 주인의 Google · Apple 로그인 필요)이 끝나고 서버를 다시 켜야 실제로 켜집니다. 그 전 빌드는 예전처럼 앱을 열 때 독촉을 가져옵니다.

## 0.2.14 (294) — 2026-09-26

**아이폰 키보드 버그.** 첫 설정의 키·나이 숫자 칸에서 키보드가 안 내려가 「확인」에 닿지 못했습니다 — 아이폰 숫자 패드에는 완료 키가 없는데 바깥 탭으로도 닫히지 않았습니다(안드로이드는 완료 키가 있어 드러나지 않음).
- 앱 전체(모든 화면 · 시트 · 다이얼로그)에서 입력칸 바깥을 탭하면 키보드가 내려갑니다. 버튼 · 칸 · 목록 행의 탭은 그대로. 스크린리더에는 이 제스처가 요소로 잡히지 않습니다.
- 목록을 끌면 키보드가 내려갑니다(첫 설정 · 목표 · 체크인 · 인바디 · 검수 · 설정 「내 몸 정보」 시트 — 첫 끌기부터 · 로그인 · 식단 검색 · 종목 고르기 · 운동 기록).
- 숫자 칸에 다음/완료 키 — 키 → 나이, 체중 → 골격근 → 체지방, 분 → 거리. 마지막 칸의 완료는 값이 맞으면 곧 확인. 검색 칸은 돋보기 키, 초대 코드 칸은 자동 교정 끔.
- 확인·저장 버튼이 키보드 위 보이는 자리에 오도록 화면마다 아이폰 키보드 높이(300px · 홈 인디케이터 포함)로 검사해 고쳤습니다 — 설정 「내 몸 정보」 시트 · 식단 양 시트(잘림) · 운동 종료 시트.
- 설정 시트의 활동량 드롭다운이 360 폭에서 옆으로 넘치던 것을 고쳤습니다. 식단 직접 입력의 g 칸에 소수점.
