# Mybody — 정보 구조 설계서 (Information Architecture) · 검증용 프로토타입 v0.1

---

## 0. ID 부여 규칙 (Feedback ID Convention)

모든 요소에 작은 회색 배지(`10px`, `opacity .55`, 우상단 또는 요소 좌측)를 붙인다. 오너는 `"P5-B3 버튼 문구 이상함"` 처럼 피드백한다.

| 접두 | 의미 | 예시 | 배지 위치 |
|---|---|---|---|
| `P##` | 페이지(화면) | `P05` | 화면 헤더 우측 |
| `M##` | 모달/팝업/시트/토스트팝업 | `M07` | 모달 헤더 우측 |
| `P##-B#` | 버튼 (페이지 소속) | `P05-B2` | 버튼 우상단 |
| `M##-B#` | 버튼 (모달 소속) | `M07-B1` | 버튼 우상단 |
| `P##-F#` | 입력 필드 | `P06-F1` | 라벨 오른쪽 |
| `P##-C#` | 카드/리스트 아이템 | `P07-C1` | 카드 좌상단 |
| `P##-T#` | 탭 | `P08-T2` | 탭 라벨 옆 |
| `P##-S#` | 빈 상태(Empty) | `P11-S0` | 빈 상태 박스 중앙 |
| `P##-E#` | 오류 상태(Error) | `P04-E1` | 오류 박스 좌측 |
| `X##` | 토스트/스낵바 | `X03` | 토스트 좌측 |
| `N-B#` | 전역 하단 네비 버튼 | `N-B2` | 아이콘 위 |

> 프로토타입 전용: 우하단 고정 `FAB` = `P99-B1` (ID 맵 오버레이 토글). 켜면 모든 배지가 노란 하이라이트로 전환되어 스크린샷 피드백이 쉬워진다.

## 1. 화면 목록 (Screens)

### P01 · 스플래시 / 시작 — `splash`
- **목적**: 첫 실행 판별(로컬 프로필 유무), 브랜드 각인 1.2초.
- **보이는 것**: 로고 "Mybody", 한 줄 카피 `"인바디 한 장이면, 계획이 나온다"`, 로딩 인디케이터.
- **할 수 있는 것**: `P01-B1 시작하기` (수동 진입용, 자동 전환 실패 시 노출).
- **진입**: 앱 실행.
- **이탈**: 프로필 없음 → `P02` / 프로필 있음 & 스캔 있음 → `P03` / 프로필 있음 & 스캔 없음 → `P04`.
- **검증 프로토타입에서**: 스킵 가능(우선순위 하). 단, 라우팅 로직 확인용으로 0.5초 버전 유지 권장.

### P02 · 온보딩 · 프로필 — `onboarding-profile`
3스텝 위저드. 상단 진행바 `P02-C0` (1/3 · 2/3 · 3/3). 스텝별로 화면을 새로 만들지 않고 한 페이지 내 스텝 전환(ID는 `P02a/P02b/P02c`로 세분).

**P02a 기본 정보**
- 보이는 것: `P02-F1 성별(남/여 토글)`, `P02-F2 나이`, `P02-F3 키(cm)`, `P02-F4 현재 체중(kg, 선택 — 인바디로 대체 가능)`
- 액션: `P02-B1 다음`, `P02-B0 건너뛰기`(→ `M22`)

**P02b 활동 수준 · 운동 경험**
- 보이는 것: `P02-F5 활동 수준` 5단계 라디오 카드(좌식 / 가벼움 / 보통 / 활동적 / 매우 활동적 — 각각 PAL 1.2~1.9 설명 문구 동반), `P02-F6 운동 경력`(입문 <6개월 / 중급 6~24개월 / 숙련 2년+), `P02-F7 주당 가능 운동 일수`(2~6 슬라이더), `P02-F8 회당 가능 시간`(30/45/60/90분)
- 액션: `P02-B2 다음`, `P02-B3 이전`

**P02c 제약 · 선호**
- 보이는 것: `P02-F9 운동 환경`(헬스장 / 홈트 / 혼합), `P02-F10 부상·질환 메모`(자유 텍스트), `P02-F11 식단 제약`(멀티칩: 채식 / 유당불내증 / 갑각류 / 견과 / 할랄 / 없음), `P02-F12 식사 횟수 선호`(3식 / 3식+간식 / 2식), `P02-F13 요리 가능 수준`(안 함·배달 / 간단 / 자유)
- 액션: `P02-B4 완료`, `P02-B5 이전`
- **완료 시**: 건강 고지 모달 `M24` 1회 노출 → 동의 → `P04`.

- **빈/오류**: `P02-E1` 필수값 누락(키·나이·성별) 시 필드 하단 인라인 에러 + `P02-B1` 비활성. `P02-E2` 비현실 값(키 <100 또는 >250, 나이 <10 또는 >100) 경고.
- **이탈**: 완료 → `P04`. 건너뛰기 → `M22` → 확인 시 기본값(남/30세/175cm/보통)으로 `P04`.

### P03 · 홈 대시보드 — `home`
- **목적**: 현재 상태 한눈 + 다음 행동 1개 제시.
- **보이는 것**:
  - `P03-C1` 최신 인바디 요약 카드 (체중 / 골격근량 / 체지방량 / 체지방률 / InBody 점수, 측정일, 직전 대비 델타 ▲▼)
  - `P03-C2` 목표 진행 카드 (목표까지 남은 kg, 진행률 도넛, D-day)
  - `P03-C3` 오늘의 플랜 카드 (오늘 운동 부위 + 오늘 섭취 목표 kcal/단백질)
  - `P03-C4` 다음 행동 배너 (조건부: "이번 주 체크인 하기" / "인바디 새로 올리기" / "목표를 설정하세요")
  - `P03-C5` 미니 추이 스파크라인 3종 (체중/골격근/체지방)
- **할 수 있는 것**: `P03-B1 인바디 올리기` → `P04` · `P03-B2 플랜 보기` → `P08` · `P03-B3 체크인` → `P09` · `P03-B4 목표 수정` → `P06` · `P03-B5 추이 상세` → `P10`
- **빈 상태**:
  - `P03-S0` 스캔 없음: "첫 인바디를 올려주세요" + `P03-B1` 강조.
  - `P03-S1` 목표 없음: `P03-C2` 자리에 "목표를 설정하면 계획이 생성됩니다" + `P03-B4`.
  - `P03-S2` 플랜 없음: `P03-C3` 자리에 "강도를 고르면 플랜이 나옵니다" + `→ P07`.
- **이탈**: 하단 네비 전역.

### P04 · 인바디 사진 업로드 — `scan-upload`
- **목적**: 인바디 결과지 이미지를 받아 판독 큐에 넣는다.
- **보이는 것**:
  - `P04-C1` 드래그앤드롭 존 (점선, "여기에 결과지를 끌어다 놓으세요")
  - `P04-C2` 촬영 가이드 썸네일 (예시 이미지 + "표 전체가 보이게, 정면에서, 그림자 없이")
  - 업로드 방식 3개: `P04-B1 사진 촬영`(→ `M01`) · `P04-B2 파일 선택` · `P04-B3 갤러리/최근`
  - `P04-B4 사진 없이 직접 입력` (수동 입력 경로 → `M05` → `P05` 빈 폼)
- **상태 머신**:
  - `idle` → `P04-C1` 기본
  - `uploading` → `P04-S3` 썸네일 + 진행바 0~100%
  - `parsing` → `P04-S4` **판독 중 상태**: 스켈레톤 + 단계 표시(`1 이미지 보정 → 2 표 영역 검출 → 3 숫자 인식 → 4 검증`), 각 단계 체크마크, 예상 3~6초, `P04-B5 취소`
  - `done` → 자동 전환 `P05`
- **오류**:
  - `P04-E1` 지원하지 않는 형식/용량 초과 → `M02`
  - `P04-E2` 판독 실패(표 검출 0) → `M03`
  - `P04-E3` 신뢰도 낮음(필수 3개 중 1개 이상 미검출) → `M04` 후 `P05`로 보내되 해당 필드 빨간 테두리
  - `P04-E4` 카메라 권한 거부 → 인라인 안내 + `P04-B2`로 유도
- **이탈**: 성공 → `P05`. 취소 → 직전 화면(`P03` 또는 온보딩 직후면 `P03`).

### P05 · 인바디 판독 결과 확인/수정 — `scan-review` ★핵심
- **목적**: OCR은 절대 완벽하지 않다. **오너가 눈으로 대조하고 고치는 화면**이 이 앱의 신뢰 축.
- **레이아웃**: 좌(또는 상단) 원본 이미지 뷰어 `P05-C0` (핀치줌/더블탭 확대, 인식된 필드에 대응하는 바운딩 박스 하이라이트), 우(또는 하단) 편집 가능한 필드 리스트.
- **필드 그룹 & ID**:
  - **A. 측정 정보** — `P05-F1 측정일시`, `P05-F2 측정 기기/장소(선택)`
  - **B. 핵심 3종 (필수·강조 카드 `P05-C1`)** — `P05-F3 체중(kg)`, `P05-F4 골격근량 SMM(kg)`, `P05-F5 체지방량 BFM(kg)`
  - **C. 파생/보조** — `P05-F6 체지방률 PBF(%)`, `P05-F7 BMI`, `P05-F8 제지방량 FFM`, `P05-F9 내장지방레벨 VFL`, `P05-F10 기초대사량 BMR(kcal)`, `P05-F11 복부지방률 WHR`, `P05-F12 InBody 점수`
  - **D. 체성분 구성** — `P05-F13 체수분 TBW`, `P05-F14 단백질`, `P05-F15 무기질`
  - **E. 부위별 근육** — `P05-F16 오른팔`, `F17 왼팔`, `F18 몸통`, `F19 오른다리`, `F20 왼다리`
  - **F. 부위별 지방** — `P05-F21~F25` (동일 5부위)
- **각 필드 UI**: 값 + 단위 + **신뢰도 점**(🟢 high / 🟡 mid / 🔴 low·미검출) + `수정` 인라인. 🔴/🟡는 기본 포커스 순서 상단으로 끌어올림.
- **자동 검증 배너 `P05-C2`** (인라인, 모달 아님):
  - `체지방률 ≈ BFM/체중×100` 불일치 → "계산값과 2%p 이상 차이납니다" + `P05-B5 계산값으로 맞추기`
  - `FFM + BFM ≈ 체중` 불일치
  - `SMM > FFM` 같은 논리 오류
  - BMI vs 키·체중 불일치
- **액션**:
  - `P05-B1 저장하고 목표 설정` → `P06`
  - `P05-B2 전부 직접 입력으로 전환` (OCR 값 비우기, → `M05` 확인)
  - `P05-B3 사진 다시 올리기` → `P04`
  - `P05-B4 나중에` (스캔만 저장, → `P03`)
  - `P05-B6 용어가 뭐예요?` → `M06`
  - `P05-B7 확장 필드 펼치기/접기` (C~F 그룹 아코디언)
- **빈 상태**: `P05-S0` 수동 입력 진입 시 — 핵심 3종만 먼저 요구하고 나머지는 "모름"으로 둘 수 있음(플랜 정확도 배지 `보통`으로 표시).
- **오류**: `P05-E1` 필수 3종 미입력 → `P05-B1` 비활성 + 인라인. `P05-E2` 범위 이탈(체중 20~300, SMM 5~70, BFM 1~120) 경고.
- **이탈**: 저장 → `P06`(목표 없음) 또는 `P10`(이미 목표·플랜 있음 = 체크인 흐름).

### P06 · 목표 설정 — `goal-setup`
- **목적**: 목표 체중 / 골격근량 / 체지방량 + 목표 날짜. **입력하는 순간 실시간 실현가능성 피드백**.
- **보이는 것**:
  - `P06-C1` 현재값 요약 리본 (P05에서 확정된 3종)
  - `P06-F1 목표 체중(kg)` — 슬라이더 + 숫자 입력 병행, 현재값 기준 ±
  - `P06-F2 목표 골격근량(kg)` — 동일 (라벨 각주: *"인바디의 '골격근량(SMM)' 기준입니다"* — 오너가 말한 "근력량"과의 매핑을 명시)
  - `P06-F3 목표 체지방량(kg)`
  - `P06-F4 목표 체지방률(%)` — F1·F3와 양방향 연동(하나 바꾸면 나머지 자동 계산, `P06-B4 연동 잠금` 토글로 고정 가능)
  - `P06-F5 목표 날짜` (달력 `M08`, 프리셋 칩: 8주 / 12주 / 16주 / 6개월)
  - `P06-F6 우선순위 선택` (체지방 감량 우선 / 근육 증가 우선 / 균형) — 강도 알고리즘 입력값
  - `P06-C2` **실시간 실현가능성 게이지** — 초록(현실적) / 노랑(도전적) / 빨강(비현실) + 한 줄 설명:
    - 주당 체중 변화율 계산 → `≤0.5%BW/주` 초록, `0.5~1.0%` 노랑, `>1.0%` 빨강
    - 근육 증가 상한: 입문 0.25~0.5kg/월, 중급 0.12~0.25kg/월, 숙련 0.05~0.12kg/월
    - 체지방·근육 동시 목표가 "리컴프"인지 판별해 별도 배지 `리컴프 구간`
  - `P06-C3` 예상 도달 시점 미리보기 미니 차트 (현재→목표 선형 + 현실 밴드)
- **액션**: `P06-B1 강도 고르기` → `P07` · `P06-B2 자동 추천 목표 채우기`(현실적 기본값 주입) · `P06-B3 초기화` · `P06-B5 이전`
- **경고**: 빨강 게이지 상태에서 `P06-B1` 누르면 → `M07` 비현실 목표 경고(진행 강행 가능, 단 `상` 강도 선택 시 `M07`의 주의 문구를 `P07`에 상시 배너로 승계).
- **빈 상태**: `P06-S0` 최신 스캔 없음 → "먼저 인바디를 등록하세요" + `→ P04`.
- **오류**: `P06-E1` 목표 날짜가 과거/7일 미만. `P06-E2` 목표 체지방률 < 남 5% / 여 12% → 안전 하한 경고(빨강 고정).
- **이탈**: → `P07`.

### P07 · 실현 강도 선택 (상 / 중 / 하) — `intensity-select`
- **목적**: 같은 목표에 대해 **3개의 서로 다른 계획 시나리오**를 비교해 하나 고르기.
- **보이는 것**: 카드 3장 (세로 스택, 모바일 기준). 상단에 `P07-C0` 목표 요약 리본 + (해당 시 `M07` 승계 경고 배너 `P07-E1`).

| 카드 | ID | 표시 항목 |
|---|---|---|
| **상 · 강하게** | `P07-C1` | 예상 도달: 10주 · 주당 -0.9%BW · 주 5~6회 운동 · 칼로리 적자 -25% · 단백질 2.2g/kg · 난이도 ★★★ · **리스크**: 근손실·정체·번아웃 가능, 외식 거의 불가 |
| **중 · 균형** | `P07-C2` | 예상 도달: 14주 · 주당 -0.6%BW · 주 4회 · 적자 -18% · 단백질 2.0g/kg · 난이도 ★★☆ · **리스크**: 주 1회 외식 허용, 대부분 지속 가능 |
| **하 · 지속 가능** | `P07-C3` | 예상 도달: 22주 · 주당 -0.35%BW · 주 3회 · 적자 -10% · 단백질 1.8g/kg · 난이도 ★☆☆ · **리스크**: 느림, 동기 유지 과제 |

## 4. 최초 사용 해피패스 (Primary Happy Path)

1. 앱을 연다 → `P01` 1.2초 → 프로필 없음 → `P02a`.

7. `P06` 목표 설정. 슬라이더로 목표 체중 74kg(-8.4), 목표 SMM 35.5(+1.4), 목표 BFM 13.5(-7.8). 목표 날짜 프리셋 `12주`. → `P06-C2` 게이지가 **노랑(도전적)**, 문구 "주당 0.7%BW — 가능하지만 이행률이 관건입니다". 우선순위는 `체지방 감량 우선`. → `P06-B1 강도 고르기`.

12. `P08-T3 식단`: 매크로 링, 끼니별 2안, 외식 가이드(주 1회 허용) 확인. `P08-C10` 장보기 리스트 `P08-B5 복사` → `X04`.

### 🔴 필수 — 이번 프로토타입에서 반드시 클릭 가능해야 함
