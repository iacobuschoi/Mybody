# 사용자 확정 요구사항 (2026-09-19 추가)

1. 플랜은 "언제 목표 달성 가능한지"를 반드시 보여줘야 한다 (실제 날짜 + D-day).
2. 실현 강도 상/중/하 = **기간 길이**로 정의한다. (난이도 라벨이 아님)

## 확정 모델
- 엔진이 먼저 `T_min` (생물학적 최단 가능 기간, 주 단위)을 계산한다.
  - T_fat  = ΔBFM / (최대 주당 체지방 감소량)
  - T_smm  = ΔSMM / (최대 주당 골격근 증가량, 훈련연차·성별·칼로리수지 보정)
  - T_min  = max(T_fat, T_smm)  → 어느 쪽이 병목인지 UI에 표시
- 상 = T_min            (최단, 식단 제약 최대)
- 중 = T_min × 1.4      (권장, 근육 보존 유리)
- 하 = T_min × 2.0      (여유, 지속성 최대)
- 각 카드: 예상 달성일(YYYY-MM-DD) · 소요 주수 · 주당 변화율 · 일일 칼로리 · 주당 운동일 · 난이도 · 리스크
- 역방향 경로: 사용자가 목표일을 먼저 지정 → 필요한 주당 속도 역산 → 실현가능/도전적/비현실적 판정

## 병목 역설 (반드시 정직하게 노출)
공격적 적자(상)는 근육 증가율을 떨어뜨리므로, 근육 목표가 병목일 때는
중강도가 상강도보다 전체 기간이 짧아질 수 있다. 이 경우 UI가 명시적으로 경고하고
중강도를 추천해야 한다. 숫자를 숨기거나 상=항상최단으로 강제하지 말 것.

## 플랜 화면 필수 요소
- D-day 카운트다운 + 목표 달성 예정일
- 주차별 예상 궤적 차트 (체중 / 골격근량 / 체지방량 3라인)
- 마일스톤 (4주 단위 중간 목표치)
- 병목 지표 배지 ("현재 병목: 근육 목표")
