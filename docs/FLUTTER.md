# 앱으로 옮기기 — 지금 어디까지 왔나

쓰던 웹 앱(`prototype/`)을 설치하는 앱(`app/`, Flutter)으로 옮기는 중입니다.
**두 앱은 같은 서버를 봅니다.** 그래서 옮기는 동안 친구들은 지금 것을
계속 쓰면 됩니다.

## 구조

```
packages/mybody_core/   화면 밖의 로직 전부 (순수 Dart — Flutter 를 안 깔아도 돌아갑니다)
  crosscheck.dart         결과지 안 숫자끼리 맞는지 검산
  engine.dart             계획 엔진 — 주차별 시뮬레이션 · 상/중/하 · 매크로 · 운동 · 식단
  modes.dart              몸만들기 모드 선택 (거부 10 · 규칙 23)
  store.dart              상태 저장소 (백업 파일이 웹 앱과 **같은 판**입니다)
  schedule.dart           주간 일정과 스트릭
  suggest.dart            "단백질 40g 남았는데 뭘 먹지"
  fooddb.dart             식품 90여 개
  data.dart · modes_data.dart · fooddb_data.dart   ← 전부 **찍어낸 것**

app/                    화면 (Flutter)
  lib/src/ui/             조각들 — 카드 · 숫자 · 차트 · 기호
  lib/src/screens/        화면
```

## 검증

### 1. 차이 검사 — 옮긴 로직이 원본과 **같은 답을 내는가**

```
node tools/difftest.js
```

같은 입력을 자바스크립트와 Dart 양쪽에 넣고 **글자 단위로** 비교합니다.
모듈 43개, 씨앗을 고정한 무작위 입력 수천 개씩. 하나라도 갈리면 그 입력을
그대로 보여 줍니다.

이렇게 하는 이유: 검산과 엔진은 **눈으로 못 봅니다.** 틀려도 그럴듯한
숫자가 나오고, 사용자는 그 숫자를 믿습니다. "옮겼습니다" 라는 말로는
아무것도 보증되지 않습니다.

실제로 이 검사가 잡은 것들:
- 나이를 안 적은 사람의 근성장이 10% 깎이고 있었습니다
  (`undefined < 18` 은 거짓, `null < 18` 은 참)
- 숙련자·상급자가 리컴프 모드로 들어오고 있었습니다 (규칙 하나를 잘못 읽음)
- 원본의 정렬 하나가 **명세에 없는 동작**에 기대고 있었습니다

### 2. 화면이 서는가

```
cd app && flutter test
```

릴리스 빌드에서 화면을 그리다 예외가 나면 Flutter 는 **아무 글자도 없는
회색 네모**를 그립니다. 콘솔에도 안 찍힙니다. 그래서 화면마다 한 번씩
세워 보고 `ErrorWidget` 이 나오는지 봅니다.

**밀어 올린 화면(push)도 봅니다.** 화면을 직접 세우는 것과 앱처럼 밀어
올리는 것은 다른 일입니다 — 그 차이를 안 봐서, 시험 열아홉 개가 통과하는
동안 검수 화면이 릴리스에서 통째로 회색이었습니다.

### 3. 글꼴 — 앱이 그리는 글자가 앱 안에 다 있는가

```
node tools/test-fontcover.js      # 확인
node tools/fix-fonts.js           # 빠진 글자 채우기
```

Flutter 는 글꼴에 없는 글자를 `fonts.gstatic.com` 에서 받아 오려 합니다.
망이 막힌 곳에서는 네모가 되고, 안 막힌 곳에서는 몸 관리 앱을 켤 때마다
구글에 신호가 갑니다.

처음 쟀을 때 화면 한 번 도는 동안 **1,900건**이 나갔습니다.

마지막 한 건은 글자가 빠져서가 아니었습니다. CanvasKit 은 `Roboto` 라는
이름의 글꼴이 앱에 없으면 **쓰든 안 쓰든** 받아 옵니다. 그래서 그 이름표를
단 48KB 짜리(NotoSansKR 의 라틴 부분)를 넣었습니다.

### 4. 눈으로 보기

```
node tools/build-flutter-web.js
STATIC=app/build/web node tools/serve.js
```

## 아직 안 옮긴 것

**플러그인이 필요해서 여기서 시험할 수 없는 것들입니다.** 코드를 쓸 수는
있지만 폰 없이 돌려 볼 수가 없어서, 확인 못 한 것을 됐다고 적지 않습니다.

- **결과지 사진 붙이기 · 자동 판독(OCR)** — 카메라/갤러리 플러그인이 필요합니다.
  지금은 숫자 세 개를 손으로 넣습니다. 이게 0층이고, 0층은 언제나 됩니다.
- **폰 알림** — FCM 설정이 필요합니다. 친구 요청 알림이 지금 앱에는 있습니다.
- **친구 소식 목록** — 서버는 이미 보내고 있고, 화면만 없습니다.
- **오프라인 큐** — 지금은 친구 관련 요청이 실패하면 그 자리에서 말합니다.
  웹 앱처럼 쌓아 뒀다 나중에 보내지는 않습니다.

## 아직 **만들어 본 적 없는 것**

개발 컨테이너에 안드로이드 SDK 가 없어서 `flutter build apk` 를 한 번도
돌려 보지 못했습니다. 지금까지 본 것은 전부 **웹으로 빌드한 것**입니다.
화면이 서는지, 숫자가 맞는지, 글꼴이 다 있는지는 그걸로 확인이 되지만
**폰에 올라가는지는 확인이 안 됩니다.** SDK 가 있는 곳에서 한 번
빌드해 봐야 합니다.

## 옮기면서 지킨 것

- **코어의 문자열은 안 고칩니다.** 웹 앱과 같은 값이어야 합니다.
  화면에서 그릴 수 없는 기호(이모지)는 화면 쪽에서 아이콘으로 바꿉니다.
- **백업 파일은 같은 판(version 1)** 입니다. 웹에서 받은 백업을 앱에서 열 수
  있고, 그 반대도 됩니다.
- **산문 데이터는 손으로 안 옮깁니다.** 모드 설명 76KB, 식품 90개, 운동
  종목 40개는 원본에서 찍어냅니다 (`tools/gen-*-dart.js`). 눈으로 옮기면
  반드시 한 글자가 틀리고, 틀린 자리는 사용자가 그대로 믿는 숫자입니다.
