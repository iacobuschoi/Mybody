# 앱 파일(APK) 만들기 · 나눠 주기

깃허브가 대신 만듭니다. 노트북에 뭘 깔 필요 없습니다.

## 받는 법

1. 깃허브 저장소 → **Actions** 탭
2. 맨 위 실행을 누릅니다 (초록 체크가 떠 있으면 다 된 것입니다)
3. 아래 **Artifacts** 에 `mybody-<번호>-apk` 가 있습니다. 누르면 받아집니다
4. 받은 zip 을 풀면 `app-release.apk` 가 나옵니다

코드를 올릴 때마다 자동으로 만들어집니다. 손으로 돌리고 싶으면
Actions → "앱 파일(APK) 만들기" → **Run workflow**.

## 폰에 넣는 법

APK 를 카톡이든 메일이든으로 보내고, 폰에서 눌러서 깔면 됩니다.
"출처를 알 수 없는 앱" 을 한 번 허용해 달라고 물어봅니다 — 그건 구글
플레이를 안 거쳐서 그렇습니다.

## 서명 열쇠 — 두 번째 앱부터 필요합니다

지금은 **디버그 열쇠**로 서명됩니다. 첫 앱을 나눠 주는 데는 아무 문제
없습니다. 문제는 그 다음입니다.

디버그 열쇠는 빌드하는 기계마다 다르게 만들어집니다. 깃허브 기계는 매번
새로 생기므로, 다음에 만든 앱은 **다른 열쇠로 서명된 다른 앱**이 됩니다.
친구 폰은 그걸 업데이트로 안 받고 이렇게 말합니다:

> 패키지가 기존 패키지와 충돌합니다

그러면 지웠다 다시 깔아야 하고, **그 폰에 있던 기록이 같이 사라집니다.**
(몸 숫자는 폰에만 있습니다. 서버에 안 올라갑니다.)

그래서 친구들한테 나눠 주기 전에 열쇠를 한 번 만들어 두는 게 낫습니다.
한 번만 하면 됩니다.

**만든 폴더는 지우지 마세요.** 잃어버리면 같은 앱의 업데이트를 영영 못
만듭니다. 클라우드 드라이브나 USB 에 한 벌 복사해 두세요.

### 만드는 법 — 명령어 하나

저장소 폴더에서 **Git Bash** 를 열고 (깃을 깔면 같이 옵니다):

```
sh tools/make-signing-key.sh
```

끝입니다. 이게 알아서 합니다:

- 열쇠를 만듭니다 (비밀번호도 알아서 만듭니다 — 외울 필요 없습니다)
- `내PC/mybody-signing-key/` 에 넣고, 거기 `KEY-INFO.txt` 에 다 적어 둡니다
- `gh` 명령이 깔려 있으면 **깃허브 금고에까지 알아서 넣습니다**
- 없으면 넣을 주소와 값을 알려 줍니다 (네 칸 복사·붙여넣기)

자바가 있어야 합니다. 안드로이드 스튜디오가 깔려 있으면 이미 있고,
없으면 [Temurin 17](https://adoptium.net/) 을 깔면 됩니다.

> 파워셸용 `tools/make-signing-key.ps1` 도 있는데, **개발하는 곳에
> 파워셸이 없어서 돌려 보지 못했습니다.** Git Bash 쪽을 권합니다 —
> 그건 끝까지 돌려 보고 결과를 확인했습니다.

### 왜 이걸 제 컴퓨터에서 해야 하나요

이 열쇠는 **앱의 신분증**입니다. 잃어버리면 같은 앱의 업데이트를 영영 못
만들고, 남이 가지면 내 앱의 업데이트인 척하는 앱을 만들 수 있습니다.
그래서 만든 자리에서 바로 깃허브 금고로 보내고 중간에 아무 데도 안
거치게 해 뒀습니다.

(클로드가 대신 만들어 줄 수도 있지만, 클로드한테는 깃허브 금고에 값을
넣는 권한이 없습니다. 그래서 어차피 붙여넣기는 똑같이 해야 하고,
대신 열쇠만 인터넷을 한 번 돌게 됩니다. 손해만 보는 교환입니다.)

### 넣고 나서 — 됐는지 보는 법

Actions 에서 한 번 더 돌립니다. 끝나면 맨 아래에 이렇게 나옵니다:

```
서명 지문 (SHA-256): AB:CD:...
```

- 열쇠를 넣기 **전** 값과 달라졌으면 잘 들어간 것입니다
- 그 뒤로는 **계속 같아야** 합니다. 돌릴 때마다 바뀌면 아직 디버그
  열쇠를 쓰고 있는 것입니다 (비밀값 이름을 잘못 적었을 때 그렇습니다)

## 가입 코드 없애기 (서버 쪽, 한 번)

친구가 계정을 만들 때 가입 코드를 묻지 않게 하려면, **서버를 띄운
컴퓨터에서** 한 줄:

```
node tools/serve.js --setup --open-signup
```

그리고 서버를 다시 띄우면 됩니다. 되돌리려면 `--close-signup`.

> 열어 두면 **주소를 아는 사람은 누구나** 계정을 만들 수 있습니다.
> 앱 파일이 공개된 곳에 있고 그 안에 주소가 들어 있으므로, 주소는
> 공개된 셈으로 보셔야 합니다. 친구들이 다 가입한 뒤에 `--close-signup`
> 으로 닫아 두는 편이 안전합니다.

## 앱 아이디

`io.github.iacobuschoi.mybody` 입니다. **누가 한 번 깔고 나면 못 바꿉니다** —
바꾸면 폰이 다른 앱으로 보고, 업데이트가 아니라 새 설치가 됩니다.

## 여기서 확인 못 하는 것

`tools/test-android.js` 는 설정 파일을 읽어서 볼 수 있는 것만 봅니다.
진짜로 폰에서 돌아가는지는 **폰에 깔아 봐야** 압니다. 첫 앱을 친구들한테
돌리기 전에 본인 폰에서 한 번 해 보세요:

- 서버 주소를 넣고 "연결" 이 되는가 (안 되면 인터넷 권한 문제입니다)
- 로그인이 되는가
- 인바디를 넣고 계획이 나오는가
