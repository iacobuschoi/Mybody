# 앱 파일(APK) 만들기 · 나눠 주기

깃허브가 대신 만듭니다. 노트북에 뭘 깔 필요 없습니다.

## 받는 법

1. 깃허브 저장소 → **Actions** 탭
2. 맨 위 실행을 누릅니다 (초록 체크가 떠 있으면 다 된 것입니다)
3. 아래 **Artifacts** 에 `mybody-<번호>-apk` 가 있습니다. 누르면 받아집니다
4. 받은 zip 을 풀면 `app-release.apk` 가 나옵니다

코드를 올릴 때마다 자동으로 만들어집니다. 손으로 돌리고 싶으면
Actions → "앱 파일(APK) 만들기" → **Run workflow**.

## 폰에 넣는 법

APK 를 카톡이든 메일이든으로 보내고, 폰에서 눌러서 깔면 됩니다.
"출처를 알 수 없는 앱" 을 한 번 허용해 달라고 물어봅니다 — 그건 구글
플레이를 안 거쳐서 그렇습니다.

## 서명 열쇠 — 두 번째 앱부터 필요합니다

지금은 **디버그 열쇠**로 서명됩니다. 첫 앱을 나눠 주는 데는 아무 문제
없습니다. 문제는 그 다음입니다.

디버그 열쇠는 빌드하는 기계마다 다르게 만들어집니다. 깃허브 기계는 매번
새로 생기므로, 다음에 만든 앱은 **다른 열쇠로 서명된 다른 앱**이 됩니다.
친구 폰은 그걸 업데이트로 안 받고 이렇게 말합니다:

> 패키지가 기존 패키지와 충돌합니다

그러면 지웠다 다시 깔아야 하고, **그 폰에 있던 기록이 같이 사라집니다.**
(몸 숫자는 폰에만 있습니다. 서버에 안 올라갑니다.)

그래서 친구들한테 나눠 주기 전에 열쇠를 한 번 만들어 두는 게 낫습니다.
한 번만 하면 됩니다.

### 1. 열쇠 만들기 (노트북에서 한 번)

자바가 깔려 있어야 합니다. 안드로이드 스튜디오가 있으면 이미 있습니다.
없으면 [Temurin 17](https://adoptium.net/) 을 깔면 됩니다.

```
keytool -genkey -v -keystore mybody.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias mybody
```

비밀번호를 물어봅니다. **적어 두세요.** 이 파일과 비밀번호를 잃어버리면
같은 앱의 업데이트를 영영 못 만듭니다 (플레이스토어에 올린 뒤라면 더
그렇습니다).

> `mybody.jks` 는 **저장소에 넣지 마세요.** `.gitignore` 가 막아 두긴
> 했습니다.

### 2. 깃허브에 넣기

파일을 글자로 바꿉니다:

```
# 윈도우 (PowerShell)
[Convert]::ToBase64String([IO.File]::ReadAllBytes("mybody.jks")) | Set-Clipboard

# 맥 · 리눅스
base64 -w0 mybody.jks | pbcopy
```

저장소 → **Settings** → Secrets and variables → **Actions** →
New repository secret 으로 네 개를 넣습니다:

| 이름 | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | 위에서 복사한 긴 글자 |
| `ANDROID_STORE_PASSWORD` | keytool 에 넣은 비밀번호 |
| `ANDROID_KEY_PASSWORD` | 같은 비밀번호 (따로 정했으면 그것) |
| `ANDROID_KEY_ALIAS` | `mybody` |

넣고 나서 Actions 에서 한 번 더 돌리면, 그때부터 만든 앱은 전부 같은
열쇠로 서명됩니다. 업데이트가 그냥 깔립니다.

빌드가 끝나면 Actions 화면 맨 아래에 **어느 열쇠로 서명했는지** 적어
줍니다. 넣었는데도 "디버그 열쇠" 라고 나오면 이름을 잘못 적은 것입니다.

## 앱 아이디

`io.github.iacobuschoi.mybody` 입니다. **누가 한 번 깔고 나면 못 바꿉니다** —
바꾸면 폰이 다른 앱으로 보고, 업데이트가 아니라 새 설치가 됩니다.

## 여기서 확인 못 하는 것

`tools/test-android.js` 는 설정 파일을 읽어서 볼 수 있는 것만 봅니다.
진짜로 폰에서 돌아가는지는 **폰에 깔아 봐야** 압니다. 첫 앱을 친구들한테
돌리기 전에 본인 폰에서 한 번 해 보세요:

- 서버 주소를 넣고 "연결" 이 되는가 (안 되면 인터넷 권한 문제입니다)
- 로그인이 되는가
- 인바디를 넣고 계획이 나오는가
