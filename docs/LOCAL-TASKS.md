- [ ] **(추가) 간식 단백질 알림**: 새 빌드 첫 실행에 알림 권한을 묻는가(안드로이드
      13+). 목표가 있고 단백질이 15g 넘게 남은 채로 앱을 켜면 알림이 예약되는가 —
      `adb shell dumpsys alarm | grep -i mybody` 또는 에뮬레이터 시계를 15:29 로
      맞추고 기다리기. 문구: "단백질 n g 남았어요. 간식으로 … 어때요?".
      설정 → 「간식 단백질 알림」 끄면 예약이 사라지는가.
- [ ] **(추가) 식단 탭 위**: 「오늘 | 달성률」 고르기가 맨 위에 있고, 달성률을 고르면
      그 자리에 주간/월간이 뜨는가(맨 아래 버튼은 없어짐). 「오늘」 카드 아래에
      「주로 먹는 것」 칩(자주 먹은 순)이 끼니 카드보다 위에 있는가.
- [ ] **(추가) 친구 상세 식단 카드**: "1800 / 2445 kcal · 74%" 처럼 먹어야 하는 것 중
      얼마나 먹었는지 퍼센트가 보이는가(막대마다, 그리고 한 줄 요약).
- [ ] **(추가) 설정**: 「서버」 카드가 없고 「계정」 카드(계정 관리 · 로그아웃)만 있는가. 맨 아래 작은 글씨 「서버 주소 바꾸기 · desktop-…」이 있는가. 로그아웃하면 설정이 닫히고 로그인 화면이 뜨는가.
- [ ] **(추가) 뭘 먹을까**가 남은 탄수·지방까지 맞추는가 — 탄수를 거의 다 먹은
      날엔 밥·면보다 단백질 위주가 위로 오는가.

끝나면 "8 끝" — 그러면 릴리스를 끊습니다. 버그가 있으면 그것만 적어 주세요.


## 9. 기록 동기화(사용자 요청) — 서버 다시 띄우고 확인

서버(db.js 동의 판 2026-09-22)와 웹(sync.js)이 바뀌었습니다 — **`node tools/launch.js`
다시.** 가입 시험은 새 동의 판을 보내야 합니다(앱·웹은 이미 맞춤).

- [ ] 앱(emutest1)에서 측정·식단이 있는 상태로 **앱 데이터 삭제**(설정 → 앱 → 저장공간
      → 데이터 삭제) → 다시 켜서 로그인 → 측정·목표·계획·식단이 **그대로 돌아오는가**
      (사진만 없음). 로그인 직후 홈이 비어 보였다가 몇 초 안에 채워져도 됨.
- [ ] 웹(emutest2)에서 뭔가 저장(운동 체크 등) → 서버 DB `records` 에
      kind='state' 행이 생기는가 → 앱에서 emutest2 로 로그인(데이터 삭제 후) →
      웹 기록이 따라오는가.
- [ ] 두 기기 충돌: 앱에서 측정 추가 → 웹은 옛것 → 웹에서 저장 → 앱을 다시 켜면
      **마지막에 바꾼 쪽(웹)**이 이기는가(앱 측정이 사라짐 — 설계대로. 같은 계정을
      두 기기에서 동시에 쓰는 사람은 없다고 봄).
- [ ] 설정에 「백업」 카드가 없고 맨 아래 「내 기록 내보내기 · 가져오기」 작은 글씨만
      있는가(서버 주소 바꾸기는 없어짐 — 서버를 옮기면 앱 업데이트).
- [ ] **음식 추가 화면(새 모양)**: 둥근 검색창 → 끼니 고르기(아침/점심/저녁/간식) →
      분류 칩 한 줄 → 목록 줄마다 왼쪽 이름·성분, 오른쪽 kcal 큼직. 고르면 아래에
      담은 것 칩이 쌓이고 「저녁에 2개 저장 · 600kcal · 단백질 40g」 버튼. 양 고르는
      시트에 배수마다 kcal 이 같이 보이고 ☆ 즐겨찾기. 온보딩 동의문이 "이 기기와 내 계정에 저장" 으로 읽히는가.

끝나면 "9 끝". 그러면 릴리스.
