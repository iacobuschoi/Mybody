# 노트북 세션(MyBody_local)이 할 일

클라우드 세션(MyBody)이 적습니다. 세션끼리 직접 메시지가 안 닿아서
**이 파일이 우편함**입니다.

- 이 파일을 읽고 아래를 순서대로 합니다.
- 결과는 `docs/LOCAL-REPORT.md` 에 적고 **커밋·push** 합니다
  (그 파일만 커밋하세요 — 코드는 클라우드가 고칩니다).
- 브랜치: `claude/body-management-app-prototype-m4mv4k`. 시작 전에 `git pull`.
- 열쇠 폴더(`~/mybody-signing-key`)는 건드리지 마세요.

## 1. 가입 코드 끄기 (서버 설정, 한 번)

```
node tools/serve.js --setup --open-signup
```

그리고 서버를 다시 띄웁니다. 사용자가 그렇게 정했습니다 — 앱에 서버
주소가 박혀 있어서 친구가 코드까지 받을 필요가 없게.

확인: 브라우저로 `https://desktop-il9c3if.tail0a8f8f.ts.net/api/health`
를 열었을 때 `"openSignup":true` 가 보이면 된 것입니다.

## 2. 안드로이드 에뮬레이터

- Android Studio 가 있으면 그 SDK 를 씁니다. 없으면 cmdline-tools 로
  SDK + platform-tools + emulator + system-image(API 34, google_apis,
  x86_64)를 받습니다.
- `flutter doctor` 에서 Android toolchain 이 초록이 되게.
- AVD 하나 만들고(Pixel 계열) 띄워서 `flutter devices` 에 보이게.

## 3. 앱 돌려 보기

```
cd app
flutter pub get
flutter run
```

아래를 **손으로** 눌러 보고, 되는 것/안 되는 것을 **화면 문구 그대로**
적습니다. 안 되는 것은 `flutter run` 콘솔의 오류 줄도 같이.

- [ ] 온보딩(키·나이·성별) → 인바디 숫자 3개 → 계획이 나오는가
- [ ] 인바디 올리기 → 「앨범에서」 사진 붙이기 → 미리보기가 뜨는가
- [ ] 「사진에서 읽기」 → 세 칸이 채워지는가
      (서버에 판독 키가 없으면 "판독 키가 설정되지 않았습니다" 가 정상)
- [ ] 측정 상세에서 붙인 사진이 보이고, 누르면 확대되는가
- [ ] 친구 탭 → 로그인 화면에 「처음이에요」「비밀번호 잊음」이 있는가
- [ ] 「처음이에요」로 가입 — **가입 코드 칸이 안 보여야** 정상(1번을 했다면)
- [ ] 가입 직후 복구 코드가 한 번 뜨는가
- [ ] 친구 탭 → 「소식」이 열리는가
- [ ] 비행기 모드 켜기 → 친구 상세 → 공유 스위치 끄기
      → "나중에 보냅니다" 가 뜨는가 → 비행기 모드 끄기 → 서버에 반영되는가
- [ ] 설정 → 내보내기 → 「복사하기」 → 붙여넣기가 되는가
- [ ] 뒤로 가기: 홈에서 뒤로 → 앱이 닫히는가 / 다른 탭에서 뒤로 → 어디로 가는가
