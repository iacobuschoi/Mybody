API 34 google_apis x86_64. 설치 경로는 E: 에 여유가 크니 E:\android-sdk 도

## 3. 앱 돌려 보기

```
cd app
flutter pub get
flutter run
```

아래를 **손으로** 눌러 보고, 되는 것/안 되는 것을 **화면 문구 그대로**
적습니다. 안 되는 것은 `flutter run` 콘솔의 오류 줄도 같이.

- [ ] **앱 첫 실행에 로그인/가입 화면이 먼저 뜨는가** (새로 바뀜 — 사진 판독은
      계정이 있어야 돼서). 「처음이에요」로 가입하면 온보딩으로 넘어가는가
- [ ] 온보딩(키·나이·성별) → 인바디 숫자 3개 → 계획이 나오는가
- [ ] 인바디 올리기 → 「앨범에서」 사진 붙이기 → 미리보기가 뜨는가
- [ ] 「사진에서 읽기」 → 세 칸이 채워지는가
      (서버에 판독 키가 없으면 "판독 키가 설정되지 않았습니다" 가 정상)
- [ ] 측정 상세에서 붙인 사진이 보이고, 누르면 확대되는가
- [ ] 친구 탭 → 로그인 화면에 「처음이에요」「비밀번호 잊음」이 있는가
- [ ] 「처음이에요」로 가입 — **가입 코드 칸이 안 보여야** 정상(1번을 했다면)
- [ ] 가입 직후 복구 코드가 한 번 뜨는가
- [ ] 친구 탭 → 「소식」이 열리는가
- [ ] 비행기 모드 켜기 → 친구 상세 → 공유 스위치 끄기
      → "나중에 보냅니다" 가 뜨는가 → 비행기 모드 끄기 → 서버에 반영되는가
- [ ] 설정 → 내보내기 → 「복사하기」 → 붙여넣기가 되는가
- [ ] 뒤로 가기: 홈에서 뒤로 → 앱이 닫히는가 / 다른 탭에서 뒤로 → 어디로 가는가
