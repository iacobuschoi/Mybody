# 내 컴퓨터에서 띄우기

미리보기 링크(claude.ai)에는 서버가 없습니다. 그래서 **자동 판독도 친구 기능도
안 됩니다** — 사진을 보낼 데가 없고, 계정을 둘 데가 없으니까요.
이 문서는 그걸 내 컴퓨터에서 돌리는 방법입니다.

처음부터 끝까지 **10분** 걸립니다. 막히면 그 자리에서 `node tools/doctor.js` 를
치세요 — 무엇이 모자란지와 무엇을 하면 되는지를 말해 줍니다.

---

## 0. 무엇이 필요한가

| | |
|---|---|
| 컴퓨터 | 맥 · 윈도우 · 리눅스 아무거나. 항상 켜 둘 수 있으면 좋습니다 |
| Node.js | 최신 LTS. <https://nodejs.org> 에서 받으세요 |
| 도메인 | **폰에서 쓸 거면** 있으면 좋습니다 (연 1~2만원). 없이도 집 안에서는 됩니다 |

> **Node 버전** — 이 서버는 Node 에 내장된 데이터베이스를 씁니다. 오래된 Node 에는
> 없습니다. 버전 번호를 외울 필요는 없습니다 — `node tools/doctor.js` 가 실제로
> 열어 보고 "된다/안 된다" 를 말해 줍니다. 안 되면 nodejs.org 에서 LTS 를 받으세요.

---

## 1. 받기

```bash
git clone -b claude/body-management-app-prototype-m4mv4k \
  https://github.com/iacobuschoi/Mybody.git
cd Mybody
```

`npm install` 은 **안 합니다.** 이 앱은 바깥 라이브러리를 하나도 안 씁니다.

---

## 2. 설정 (한 번만)

```bash
node tools/serve.js --setup
```

묻는 것은 네 가지입니다. 그냥 엔터를 치면 기본값이 들어갑니다.

- **운영자 이름** — 개인정보처리방침에 적힙니다. 본명이 아니어도 됩니다.
- **연락처** — 메일이든 오픈채팅 링크든. 비워 두면 "주소를 알려준 사람에게
  직접 말하세요" 라고 나갑니다. 친구 몇 명과 쓸 거면 그걸로 충분합니다.
- **포트** — 8080 그대로 두면 됩니다.
- **ANTHROPIC_API_KEY** — 사진에서 숫자를 **자동으로 읽게** 하려면 필요합니다.
  없어도 앱은 그대로 씁니다(숫자를 직접 넣으면 됩니다). 나중에 넣어도 됩니다.
  받는 곳: <https://console.anthropic.com/settings/keys> (로그인 → Create Key).
  쓴 만큼 요금이 붙습니다. 결과지 한 장에 1원 안팎이고, 하루 판독 횟수는
  서버가 40회로 막아 둡니다(`OCR_PER_DAY` 로 바꿀 수 있습니다) — 실수로
  많이 쓰는 일을 막기 위해서입니다.

이때 **가입 코드**가 한 번 나옵니다. 이 값을 아는 사람만 계정을 만들 수 있습니다.
어딘가에 적어 두고, 친구에게는 직접 주세요.

설정은 `~/.mybody/config.json` 에 저장됩니다. 저장소 안이 아니라 홈 폴더입니다 —
저장소에 두면 언젠가 git 에 들어가고 가입 코드와 API 키가 같이 나갑니다.

바꾸고 싶으면 다시 `--setup`, 지금 값만 보려면 `node tools/serve.js --show`.

---

## 3. 띄우기

```bash
node tools/serve.js
```

이게 전부입니다. 빌드가 없거나 낡았으면 알아서 만들고 서버를 띄웁니다.

```
Mybody 서버 실행 중
  주소   http://localhost:8080
  폰에서 http://192.168.0.5:8080   (같은 와이파이)
```

브라우저에서 <http://localhost:8080> 을 열면 됩니다.
**폰에서 칠 주소도 같이 찍어 줍니다** — 그 줄을 그대로 폰에 치면 됩니다.
끌 때는 터미널에서 **Ctrl+C**.

> 터미널을 여는 것부터 귀찮으면, 저장소 폴더의 **`start.command`(맥)** ·
> **`start.cmd`(윈도우)** 를 더블클릭해도 같습니다.

## 4. 폰에서 쓰기

여기서 길이 갈립니다. **폰에서 쓰는 게 목적이라면 4-B(터널)를 권합니다.**
친구 알림을 폰으로 받으려면 4-B 말고는 방법이 없습니다.

### 4-A. 같은 와이파이에서 바로 (0분, 대신 넷이 안 됨)

컴퓨터의 내부 주소(예: `192.168.0.5`)를 폰 브라우저에 칩니다.

되는 것: 측정 입력 · 목표 · 계획 · 식단 · 사진 촬영 · 자동 판독 ·
친구 기능 · 앱 안 친구 소식
**안 되는 것 넷:**

- **폰 알림** — 친구가 운동해도 잠금화면에 안 뜹니다 (앱을 열면 친구 탭에
  소식으로 쌓입니다)
- **폰에 앱처럼 깔기** — 설치 버튼이 아예 안 뜹니다
- **오프라인으로 열기** — 와이파이가 끊기면 안 열립니다
- **버튼으로 복사하기** — 초대 코드 · 복구 코드를 손으로 옮겨 적어야 합니다

브라우저가 `https` 가 아닌 주소에서 이 넷을 막기 때문입니다. 앱의 문제가
아니라 브라우저 규칙이고, 우회할 방법이 없습니다. 앱도 화면에서 이 사실을
그대로 말합니다 — "알림을 켤 수 없습니다" 가 아니라 왜 안 되는지를요.

### 4-B. 터널로 열기 (권장 — 넷 다 됩니다)

**주소는 한 번 정하면 바꾸지 마세요.** 브라우저는 측정 기록을 주소별로 따로
저장합니다. 주소가 바뀌면 친구들 폰에서 그동안의 기록이 통째로 안 보이게 되고,
본인은 그걸 알 방법이 없습니다.

그래서 **이름 있는 터널**을 씁니다. 도메인이 하나 필요합니다.
설치와 만드는 법은 Cloudflare 문서를 보세요:
<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/>

만들고 나면 이렇게 띄웁니다:

```bash
# 터미널 1
node tools/serve.js

# 터미널 2
cloudflared tunnel run 내터널이름
```

그리고 설정에 그 주소를 넣어 두세요 — 터널 뒤에서 사람별로 요청을 세게 됩니다:

```bash
node tools/serve.js --setup --origin="https://mybody.내도메인.com"
```

도메인이 없으면 `cloudflared tunnel --url http://localhost:8080` 로 임시 주소를
받을 수 있습니다. **띄울 때마다 주소가 바뀌므로 혼자 시험할 때만 쓰세요.**

#### 폰 알림 켜기 (터널을 쓸 때만)

열쇠를 한 번 만들어 둡니다:

```bash
node tools/push-keys.js
```

그 다음 각자 폰에서 **친구 탭 → 폰 알림 → 알림 켜기** 를 누르면 됩니다.
친구가 운동을 체크하면 앱을 안 열어도 잠금화면에 한 줄 뜹니다.

- 오는 것은 **"누가 운동했다" 뿐**입니다. 안 한 것은 알림이 오지 않습니다 —
  그렇게 만들어 뒀습니다.
- 일정을 안 보여주기로 한 친구에게는 알림도 안 갑니다. 알림이 공유 설정을
  우회하는 뒷문이 아닙니다.
- 아이폰은 **홈 화면에 추가한 뒤에만** 알림이 됩니다 (Safari 규칙).
- 열쇠를 다시 만들면(`--force`) 지금 켜 둔 사람들이 전부 다시 켜야 합니다.

### 폰에 앱처럼 깔기

`https` 주소를 폰에서 열고:

- **아이폰(사파리)** — 공유 → 홈 화면에 추가
- **안드로이드(크롬)** — 주소창 옆 설치 아이콘, 또는 메뉴 → 앱 설치

## 5. 친구 들이기

1. 친구에게 **주소**와 **가입 코드**를 줍니다 (카톡으로 보내면 됩니다).
2. 친구가 그 주소에서 계정을 만듭니다. 가입 코드는 가입할 때만 필요합니다.
3. 서로 **초대 코드**(8자리)를 주고받아 친구를 맺습니다.
   전화번호나 이메일로는 서로를 못 찾습니다 — 일부러 그렇게 만들었습니다.
4. 몸에 대한 항목은 기본이 전부 꺼져 있습니다. 친구마다 직접 켜야 나갑니다.
   기본으로 켜져 있는 것은 **행동에 대한 둘**뿐입니다 — 이번 주에 기록을
   했는지, 그리고 "계획 O일 · 지킴 O일" 두 숫자. 무슨 요일에 무슨 운동을
   했는지는 나가지 않습니다.

친구에게 이것들을 미리 말해 주세요:

- 측정 기록은 **각자 폰에만** 있습니다. 서버에는 친구에게 보일 주간 요약만 갑니다.
- 친구를 맺으면 **운동 일정 숫자 두 개**(계획한 날 · 지킨 날)와 이번 주에
  기록했는지 여부가 기본으로 보입니다. 친구 화면에서 한 번 눌러 끌 수 있습니다.
- 폰 알림을 켜면 친구가 운동을 체크할 때 알림이 옵니다. **안 한 것은
  안 옵니다.** 알림을 켜고 끄는 건 각자 자기 폰에서 합니다.
- 그래서 폰을 바꾸면 기록이 안 따라옵니다 — 설정 → 내보내기 → 파일로 저장.
- 가입할 때 나오는 **복구 코드**를 적어 둬야 합니다. 비밀번호를 잊으면 그것뿐입니다.
- 내 컴퓨터가 꺼져 있으면 친구 기능만 안 됩니다. 나머지는 그대로 됩니다.

## 6. 계속 켜 두기

노트북을 닫으면 서버가 죽습니다. 친구가 접속을 못 하고, 내 앱도 친구 화면만
비어 보입니다(내 기록은 폰에 있으니 그대로 됩니다).

컴퓨터를 켜면 서버도 같이 켜지게 하려면:

```bash
node tools/autostart.js          # 내 OS 에 맞는 설정을 보여줍니다
node tools/autostart.js --write  # 그대로 만들어 줍니다
```

맥이면 launchd, 윈도우면 작업 스케줄러, 리눅스면 systemd 설정을 만듭니다.
거는 명령까지 같이 알려 줍니다.

> 직접 쓰지 말고 이 도구를 쓰세요. 자동 시작은 평소 쓰는 PATH 도 HOME 도
> 안 물려받아서, 손으로 적으면 `node` 를 못 찾거나 설정 파일을 못 찾는 데서
> 막힙니다. 이 도구는 지금 돌고 있는 노드의 실제 경로를 박아서 만듭니다.

계속 켜 두려면 항상 켜 있는 기계(라즈베리파이 · 미니PC · 클라우드)로 옮기는
게 낫습니다. 같은 명령이 그대로 돕니다.

### 백업

```bash
node tools/backup.js
```

서버를 끄지 않아도 됩니다. `~/mybody-backups/` 에 그날 날짜로 하나 뜨고,
30일 지난 것은 알아서 지웁니다.

```
백업했습니다: /Users/나/mybody-backups/mybody-2026-09-20.db  (68KB)
  계정 3명 · 친구 0건 · 주간 요약 0건
```

계정 수까지 찍어 주는 이유가 있습니다 — **파일을 그냥 복사하면 안 됩니다.**
서버가 켜져 있는 동안 새 기록은 `mybody.db-wal` 이라는 곁파일에 쌓이고
본파일은 거의 안 자랍니다. 계정을 하나 만든 직후 실제로 이랬습니다:

```
mybody.db       4,096 바이트
mybody.db-wal 152,472 바이트   ← 계정이 여기 있습니다
```

이때 `mybody.db` 만 복사하면 **테이블조차 없는 파일**이 나옵니다. 백업한 줄
알았는데 아무것도 없는 상태가 제일 나쁩니다. `tools/backup.js` 는 SQLite 에게
직접 온전한 사본을 만들게 시킵니다.

(Ctrl+C 로 제대로 끄면 곁파일이 본파일에 합쳐져서 파일 하나가 됩니다.
그때는 복사해도 됩니다. 하지만 켜져 있을 때 뜨는 백업이 훨씬 자주 필요합니다.)

```bash
# 매일 새벽 4시 (crontab -e)
0 4 * * * cd ~/Mybody && /usr/local/bin/node tools/backup.js
```

`node` 의 전체 경로를 적으세요 — 크론에는 평소 쓰는 PATH 가 없습니다.
`which node` 로 확인할 수 있습니다.

되돌릴 때는 **서버를 먼저 끄고**:

```bash
node tools/backup.js --list                                  # 뭐가 있나
node tools/backup.js --restore ~/mybody-backups/mybody-2026-09-20.db
```

지금 파일은 `.before-…` 로 옆에 치워 두니, 되돌린 게 마음에 안 들면
그걸로 돌아갈 수 있습니다.

> 30일 지난 백업을 지우는 것은 예의가 아니라 약속입니다. 누가 계정을 지워도
> 옛 백업에는 그 사람의 몸 숫자가 그대로 남습니다. 지우기로 한 것이 어딘가에
> 남아 있으면 지운 게 아닙니다. 방침에도 "최대 30일" 이라고 적혀 있습니다.

## 뭔가 안 될 때

```bash
node tools/doctor.js
```

이걸 먼저 치세요. 항목마다 무엇을 하면 되는지 적혀 있습니다.

| 증상 | 보통 이것 |
|---|---|
| 친구가 접속을 못 한다 | 아래 순서대로 |
| 화면에 이상한 번호 배지가 잔뜩 뜬다 | 개발 빌드가 나간 것입니다. `node tools/serve.js` 로 띄우면 안 그럽니다 |
| 앱 설치 버튼이 안 뜬다 | `https` 가 아니어서입니다 (4-B) |
| 고쳤는데 폰에서 안 바뀐다 | 앱을 완전히 닫았다 다시 여세요 (두 번). **지웠다 다시 깔지 마세요 — 측정 기록이 같이 사라집니다.** 꼭 필요하면 먼저 설정 → 내보내기 → 파일로 저장 |
| 자동 판독이 안 보인다 | API 키가 없거나 설정에서 안 켰습니다. 앱의 인바디 올리기 화면이 이유를 말해 줍니다 |

### 친구가 접속을 못 할 때 — 이 순서로

1. **내 컴퓨터에서** <http://localhost:8080> 이 열리나?
   안 열리면 서버가 죽은 것입니다 — `node tools/serve.js` 를 다시 치세요.
2. **터널 주소**를 내 폰에서 열어 보세요 (와이파이를 끄고 LTE 로).
   안 열리면 터널이 죽은 것입니다 — `cloudflared tunnel run` 을 다시 띄우세요.
3. 친구에게 **주소를 정확히** 줬나요? `https://` 까지 포함해서요.
4. 친구가 **가입 코드**를 맞게 넣었나요? `node tools/serve.js --show` 로 확인하고
   다시 보내 주세요.
5. 친구가 계정은 만들었는데 서로 안 보인다면 — **초대 코드**를 주고받아
   친구 요청을 보내고 **수락**까지 했는지 확인하세요. 보낸 쪽 친구 탭에
   "보낸 요청 1건 · 수락을 기다리는 중" 이 보입니다.
6. 서버 터미널 창에 뭐가 찍혀 있는지 보세요. 포트 충돌이나 개발 빌드
   경고는 거기 나옵니다.

남에게 널리 열 생각이면 `docs/DEPLOY.md` 와 `node tools/preflight.js` 를 먼저
보세요. 거기에는 친구 몇 명과 쓸 때는 넘어가도 되는 것들까지 들어 있습니다.
