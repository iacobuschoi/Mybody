# 2026-10-13 · 「누르고 말하기」 · 세트별 기록 · 지난 기록 — 에뮬레이터 시험과 UI·UX 검토

기능 브랜치 `claude/voice-set-entry` (base: `claude/body-management-app-prototype-m4mv4k` ae08e02).
맥에 안드로이드 폰이 연결돼 있지 않아 **안드로이드 에뮬레이터(Pixel 6 · API 36 · `lab-36`)** 에서
시험했습니다. 실기기가 아닙니다. 스크린샷은 `docs/shots/0.2.22-voice/`.

## 시험한 시나리오 (전부 통과)

1. 로그인 없이 쓰기 → 온보딩 → 홈 → 오늘 칸에 「헬스 하기로」 → 「운동 시작」 → 헬스 화면.
2. **꾹 누르기(실제 경로)**: 마이크 권한 창이 뜸 → 허용 → 다시 꾹 누르고 뗌 → 에뮬레이터에 마이크 입력이
   없어 「못 들었어요 — 꾹 누른 채 말하고 떼 주세요. 짧게 누르면 글로 넣습니다」 토스트, 단추는 원래대로.
   (첫 빌드에서는 권한 창이 뜬 사이 손을 뗐는데도 「듣는 중」 에 갇혔습니다 — 고쳤습니다.)
3. **글로 넣기(받아쓴 글을 넣는 길)**: 짧게 누름 → 「벤치 80키로 4개」 → 확인 시트 「이렇게 들었어요 /
   바벨 벤치프레스 ▾ / 80kg / 4회 / 세트 수 1 / 1세트 기록」 → 기록 → 목록 끝에 벤치프레스 줄이 더해지고
   칩 「1 80×4 🎤」, 시계 시작, 휴식 2분, 머리글 1/18 세트, 토스트 「바벨 벤치프레스 — 1세트 기록했습니다」.
4. **「세트」 길게**: 시트 「바벨 벤치프레스 · 새 세트 / 80 kg / 4회 / 8회·10회·12회 / 세트 완료」 → 무게 +
   (82.5) · 8회 → 완료 → 칩 「2 82.5×8」, 줄의 무게 단추 82.5kg.
5. **칩 누르기**: 「바벨 벤치프레스 · 1세트 / 확인 / 이 세트 지우기」.
6. **종료 → 저장**: 「오늘 헬스 / 01:31 / 완료 세트 2 / 8 kcal」 → 저장 → 축하 → 홈 「헬스 완료 · 2분 · 약 8kcal」.
7. **지난 기록**: 홈 「이번 주 운동」 의 시계 → 날짜별 「10/13 (화) · 헬스 · 2분 · 2세트 · 8 kcal · 바벨
   벤치프레스 · 80×4 · 82.5×8」 → 종목별 「1번 · 마지막 10/13 (화) · 최고 82.5kg」 → 상세 「한 날 1번 · 최고
   82.5kg · 볼륨 980kg · 1 80×4 · 2 82.5×8 · 계획 3세트 × 8-12」.

## 시험 중 고친 것 (새 기능 안에서)

- 권한 창이 뜨는 사이 손을 떼면 듣기를 시작하지 않음 · 기기가 먼저 끝내면(소리 없음 · 시간 초과 · 오류)
  단추가 바로 돌아오고 이유를 말함.
- 「누르고 말하기」 단추를 목록 끝(스크롤 너머)에서 **화면 아래 고정**으로.
- 운동을 다 한 날은 홈에서 운동 화면으로 가는 단추가 사라져 지난 기록에도 못 가던 것 → 홈 「이번 주
  운동」 카드와 설정 → 화면에 「지난 운동 기록」 진입점.

## UI·UX 검토에서 찾은 것 — 고치지 않고 목록만

새 기능 밖의 것입니다. 번호는 순서일 뿐 우선순위가 아닙니다.

1. **추이 탭 x축**: 측정이 하나뿐일 때 x축 눈금이 「10/13 · 10/14 · 10/14」 처럼 같은 날이 두 번 찍힙니다
   (체중 · 골격근 · 체지방률 세 차트 모두).
2. **홈 브리핑 「헬스 완료 · 2분 · 약 8kcal」** 가 누를 수 없는 글자입니다. 방금 한 기록으로 가는 길(기록 ·
   지난 기록)이 여기에 있는 것이 자연스럽습니다. 지금은 카드 오른쪽 끝의 시계 아이콘만 있습니다.
3. **운동을 다 한 날 운동 화면에 다시 못 들어감**: 홈 「헬스 하러 가기」 가 사라지고 날짜 시트에도 「열기」 가
   없습니다. 세트를 더 적거나 잘못 적은 것을 고치려면 길이 없습니다(지난 기록 화면은 읽기만).
4. **플랜 탭에 플랜이 없으면 빈 화면**: 「목표 정하기」 만 있고 달성률 · 지난 운동 기록 단추가 안 보입니다.
   목표 없이 운동만 적는 사람(로그인 없이 쓰기 · 추정치)에게는 운동 기록이 어디 있는지 보이지 않습니다.
5. **홈 날짜 시트의 스위치가 시트가 올라오는 동안 움직입니다**: 자동화에서 「헬스 하기로」 를 눌렀는데
   「유산소 하기로」 가 켜진 적이 두 번. 사람 손가락도 빨리 누르면 같은 일이 날 수 있습니다 — 시트가 자리
   잡은 뒤에 스위치가 반응하거나, 스위치 줄 높이를 고정하는 쪽이 안전합니다.
6. **목표 → 「기간 계산하기」 단추가 첫 화면 밖**: 360×780 기준이 아니라 1080×2400 에서도 스크롤해야
   보입니다(목표 카드가 깁니다). 한 번 더 스크롤하면 되지만, 첫 사용자가 「다음에 뭘 누르지」 를 찾습니다.
7. **「장기 목표는 동기를 잃기 쉬워요!」 대화상자에서 「그대로 가기」** 를 눌렀는데 기간 기준 화면으로 넘어간
   것으로 보였습니다(자동화라 정확한 원인은 못 봤습니다 — 손으로 한 번 확인 필요).
8. **기간 기준 목표 화면의 「이 계획으로 시작하기」** 를 눌러도 홈에 「운동 계획이 아직 없어요」 가 그대로였습니다
   (자동화 · 한 번). 플랜이 실제로 저장되는지 손으로 확인 필요.
9. **헬스 화면 축하 문구**: 2분 · 8 kcal 에도 「약 8 kcal 소모했어요! 축하합니다」 — 아주 짧은 세션(예: 실수로
   저장)에는 문구를 줄이는 쪽이 덜 어색합니다.
10. **헬스 화면 발 줄 안내문** 「꾹 누른 채 「벤치 80키로 4개」 — 떼면 확인하고 기록」 이 1080px 폭에서 두 줄로
    접힙니다. 짧게 줄이거나 처음 몇 번만 보이게 하는 것이 낫습니다(새 기능 — 다음 판에서 다듬을 것).
11. **확인 시트의 「세트 수」 줄** 이 무게 · 횟수 밑으로 혼자 내려갑니다(Wrap). 좁은 폰에서는 더 그렇습니다 —
    「세트 수」 를 오른쪽 끝 작은 스테퍼로 두거나 두 줄 격자로.
12. **식단 탭 「아직 하루 목표가 없습니다 → 플랜 만들기」** 와 홈 「목표 정하기」 가 같은 곳으로 가는데 이름이
    다릅니다(플랜 만들기 / 목표 정하기 / 목표 설정).
13. **친구 탭(로그인 없이)**: 「로그인」 단추만 — 「로그인 없이 쓰기」 를 고른 사람에게 무엇을 잃는지는 가입
    화면에서만 말합니다. 한 줄이면 됩니다(여기엔 이미 한 줄 있음 — 괜찮음, 참고만).
14. **설정의 「운동 장소와 기구」 카드** 가 한 화면을 다 차지합니다(1076px). 접힌 요약 한 줄 + 펼치기가 낫습니다.
15. **온보딩 2/3 「주당 운동」 슬라이더** 의 값 표시(「4일」)가 슬라이더 위에 떠 있어 접근성 트리에
    ValueIndicator 로 전체 화면 크기로 잡힙니다 — 보이는 문제는 아니고 스크린리더 · 자동화에만 걸립니다.
16. **헬스 화면 종목 줄이 접근성 트리에 없음**: ReorderableListView 의 줄(종목 이름 · 세트 단추 · 무게 단추)이
    uiautomator 에 안 잡힙니다 — TalkBack 사용자도 같은 것을 못 볼 수 있습니다. 확인 필요.

## 알려진 한계

- 에뮬레이터에는 마이크 입력이 없어 **실제 음성 인식 정확도는 못 봤습니다.** 받아쓴 글 → 세트 변환은
  순수 Dart 파서(`voice_set.dart`)라 시험 23개로 덮었고, 기기에서는 글로 넣는 길로 같은 코드를 지났습니다.
- iOS 는 빌드하지 않았습니다(Info.plist 문구만 더함).
