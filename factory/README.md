# 앱 공장 — 주제 한 줄에서 스토어까지, 주인은 승인 버튼만

> **한 줄:** 주인이 Claude 앱에 주제를 던지면, 클라우드의 Claude 가 조사 · 기획 · 설계 · 구현을 하고, 맥 미니의
> 폰들에서 시험하고, 스토어 등록까지 준비해 두면, 주인이 폰에서 **승인 한 번** — 스토어로 나갑니다.
> 주인은 하루 한 번 요약을 받습니다.

이 폴더는 그 공장의 **설계도와 씨앗**입니다. MyBody 를 만들며 겪은 것을 데이터로 삼았고([LESSONS.md](LESSONS.md)),
Claude Code · 스토어 · 시험 도구의 2026-09 현재 사실을 확인해 썼습니다. 새 저장소 `app-factory` 를 만들 때 `seed/` 를
그대로 복사하고 이 문서들을 `docs/factory/` 에 넣습니다.

## MyBody 와 무엇이 다른가 (요약)

| MyBody | 공장 |
|---|---|
| 클라우드 ↔ 노트북이 **문서 우편함**으로 편지, 주인이 "n번 해줘" 전달 | 정해진 일은 **GitHub 워크플로 → 맥 미니 러너**, 즉석 일은 **세션 메시지**(승인 안 걸리게 설정). 사람은 통로가 아님 |
| 노트북 세션이 **60개 항목**을 에뮬레이터에서 손으로 확인 | Maestro 흐름 + AI 탐색 시험이 실기기에서 자동. 결과는 `summary.json` + 스크린샷 + 커밋 상태 |
| 서버 11번 재시작 · git pull 7번 · "N 끝" 12번 | 완료는 GitHub 이벤트가 알림. 서버는 VM · 옛 판 호환 규칙 |
| 릴리스 AAB 를 손으로 받아 콘솔에, 서명 안 된 것 · 디버그 서명이 초록으로 통과 | 결과물을 열어 지문 · 판 · 권한을 검사. 업로드는 API. 첫 AAB 만 콘솔 |
| 판 번호를 두 세션이 각자 정해 어긋남 | 태그 하나 · 빌드 번호 = 커밋 수 |
| 세션 하나가 모든 것을 순차로, 검토 5차 | 앱마다 스레드 · 검토 관점 병렬 · 프로젝트 기억으로 결정 공유 |
| 출시가 "주인이 콘솔에서 하는 40분" | **주인은 승인 버튼 하나.** 열쇠는 승인 뒤에만 풀림(공개 저장소의 환경 보호 규칙) |

## 이 설계가 기대는 사실 (2026-09-24 확인)

- Claude Code **Projects**(Pro/Max 베타, 점진 배포): 코디네이터 대화 + 병렬 클라우드 스레드 + 공유 기억 · 지침 + Overview 「Waiting on you」 + 프로젝트 루틴. 로컬 세션은 프로젝트에 못 들어감.
- **Routines**: 스케줄 · API · GitHub(PR · 릴리스) 트리거, 매 실행 새 세션, 하루 실행 상한, 푸시/이메일 알림.
- **Remote Control**: 로컬 세션을 폰에서 조종 · 폰 푸시 · 클라우드 ↔ 로컬 세션 메시지(받는 쪽 `crossSessionInbound` 로 승인 문제 해결).
- **GitHub**: 개인 Free/Pro/Team 은 **공개 저장소에서만** Required reviewers → 출시 창구를 공개 · 코드 없는 저장소로 분리. self-hosted 러너 무료(2025-12 과금 연기), macOS ARM64 지원.
- **스토어 API**: 앱 생성 · 애플 개인정보 답안 · 플레이 첫 AAB · 앱 콘텐츠 선언은 콘솔에서만. 나머지(문안 · 스크린샷 · 가격 · 심사 제출 · 트랙 · 단계적 배포)는 API.
- **시험 도구**: Maestro 는 실제 아이폰 미지원 → Patrol/integration_test. mobile-mcp 는 실기기 · 시뮬 모두.
- **정책**: 애플 4.3(b) 2026-06 개정(반복 제출 → 프로그램 제외 가능) · 구글 연결 계정 정지 · 개인 계정 12명·14일 테스트 · targetSdk 36 · 16KB · Xcode 26.

바뀔 수 있는 것들입니다. 첫 앱을 내기 전에 [MONEY.md](MONEY.md) 12절 「확인 못 한 것」과 함께 한 번 더 봅니다.
