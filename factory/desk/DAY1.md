# 첫날 — 오늘 산 것으로 맥 미니 세팅하고 책상 시스템 돌리기

오늘 구성: **TV(화면) · 맥 미니 내장 스피커(소리) · Brio 100(마이크 · 카메라) · 무선 키보드 · M171 마우스 · 아이폰 12**.
모니터 · 스피커폰은 써 보고 나중에. 대략 1시간(대부분 내려받기 대기).

---

## 1. 꽂기 (5분)

| 맥 미니 뒤 | 꽂을 것 |
|---|---|
| HDMI | **TG HDMI 케이블 → TV** |
| USB-A ① | **Brio 100** |
| USB-A ② | **NEXTU 허브** (허브 어댑터는 콘센트에 · 포트 스위치 4개 전부 켜기) |
| USB-C ①② | 비워 둠 (C to HDMI 케이블은 모니터 올 때) |

허브에: **키보드 수신기 · M171 수신기 · 벨킨 케이블 → 아이폰**.
키보드는 뒤/옆 스위치를 **「무선(수신기)」 모드**로, 마우스 전원 켜기. 마지막에 맥 미니 전원.

TV: 리모컨으로 해당 HDMI 입력 선택 → **입력을 "PC"로 · 게임 모드 · 화면 크기 "화면 맞춤"**.

## 3. 시스템 설정 (10분) — 왼쪽 메뉴에서

| 어디 | 바꿀 것 | 왜 |
|---|---|---|
| **사용자 및 그룹** | 「자동으로 로그인」→ 내 계정 | 정전 · 재시동 뒤에도 박수 대기 상태로 |
| **잠금 화면** | 「화면 보호기 시작」→ 안 함 · 「화면 보호기 시작 또는 디스플레이가 꺼진 후 암호 요구」→ **안 함** | 키보드 없이 켜려면 필수 |
| **디스플레이** | 해상도 → **「텍스트 크게」** 쪽 | 침대에서 읽히게 |
| **손쉬운 사용 → 읽기 및 말하기** | 시스템 음성 → 음성 관리 → 한국어 **Yuna (프리미엄)** 내려받기 → 고르기 | 안내 목소리 |
| 손쉬운 사용 → 음성 제어 | **꺼져 있는지** 확인 | 같은 말이 두 번 실행됨 |
| **키보드 → 텍스트 입력 → 입력 소스** | 「한국어 2벌식」 추가 · 「Caps Lock 으로 입력 소스 전환」켜기 | 한/영 전환 |
| 소프트웨어 업데이트 → 자동 업데이트 | 「macOS 업데이트 설치」끔 (보안 응답은 켜 둠) | 밤에 혼자 재시동하지 않게 |

## 4. 한 줄 설치 (30~40분, 대부분 기다림)

**⌘ + Space → "터미널" → 엔터**, 그리고 이 줄을 붙여 넣고 엔터:

```
bash <(curl -fsSL https://raw.githubusercontent.com/iacobuschoi/Mybody/claude/app-dev-automation-workflow-h4d88r/factory/desk/day1.sh)
```

암호를 물으면 맥 로그인 암호(입력해도 화면에 안 보이는 게 정상). 끝나면 남은 것 다섯 줄이 나옵니다.

- 도중에 **「python 이(가) 마이크에 접근하려고 합니다」** 가 뜨면 **허용**.
- 「개발자 도구를 설치하시겠습니까?」 가 뜨면 **설치** (Homebrew 가 필요로 함).

## 5. 로그인 · 시험 (10분)

```
claude                       # 뜨면 /login → 브라우저에서 claude.ai 로그인 → 돌아와서 /exit
cd ~/lab/desk
.venv/bin/python -m desk selftest     # 마이크 · 말하기 · 받아쓰기 · Claude · 브리핑 — 전부 OK 인지
.venv/bin/python -m desk calibrate    # 침대 쪽에서 박수 두 번 → ★ 묶음 끝: 박수 2번 이 뜨는지. Ctrl+C 로 끝
deskctl sleep                         # 화면이 꺼짐
```
그리고 **박수 두 번** → TV 가 켜져 있으면 화면이 돌아오고, 꺼져 있어도 **맥 스피커로 "시스템을 시작합니다"** + 브리핑.
그다음 "지금 몇 시야", "브리핑", "조용히", "다시 들어", "화면 꺼" 를 말해 보세요.

`gh auth login` (GitHub 로그인)은 공장 상황을 브리핑에 넣을 때 — 오늘은 건너뛰어도 됩니다.

## 오늘 알아둘 것

- **TV 는 신호가 끊기면 스스로 꺼지고, 다시 와도 알아서 안 켜집니다.** 그래서 박수를 쳐도 TV 가 꺼진 채일 수 있습니다 —
  목소리는 맥 내장 스피커로 나오니 시스템이 깬 건 들립니다. TV 는 리모컨으로 켜 주세요.
  **TV 브랜드 · 연식을 알려 주면** 박수 → TV 켜기를 붙입니다(LG webOS · 삼성 타이젠은 와이파이로 켜고 끌 수 있음).
- 맥 내장 스피커는 작습니다. 침대에서 안 들리면 `소리 키워` 라고 말하거나 config 의 `rate` 를 낮춰 천천히.
- Brio 마이크로 침대에서 말이 잘 안 먹히면 그때 스피커폰을 삽니다 — 그 판단이 오늘 시험의 목적입니다.
- 로그: `tail -f ~/Library/Logs/deskd.log` · 다시 띄우기: `launchctl kickstart -k gui/$(id -u)/lab.deskd`
