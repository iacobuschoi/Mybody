## 0. 출근 전에 30초 — 이메일 두 군데
개인정보처리방침과 계정 삭제 페이지의 「여기에 연락받을 이메일 주소를 적어 주세요」
자리를 채워야 합니다. 저장소 `docs/privacy.html` 137행쯤, `docs/delete-account.html` 「3. 이메일로 요청」.
고치고 푸시하면 몇 분 뒤 https://iacobuschoi.github.io/Mybody/privacy.html 에 반영됩니다.
(GitHub Pages 는 켜져 있습니다 — Source=GitHub Actions, 「방침 페이지 올리기」 워크플로가 `docs/` 를 올립니다. 안 열리면 Actions 에서 그 워크플로가 초록인지 보세요.)

## 1. 콘솔 → 앱 만들기 (2분)
play.google.com/console → 모든 앱 → **앱 만들기**
- 앱 이름 `Mybody` · 기본 언어 한국어 · 앱 · 무료 → 선언 두 개 체크 → 만들기.

## 2. 앱 서명 — **AAB 를 올리기 전에** (10분)
왼쪽 메뉴 「Google Play로 보호됨 → Play 스토어 배포 → **Play 앱 서명**」
(안 보이면 「테스트 및 출시 → 앱 무결성 → Play 앱 서명」, 또는 「출시 → 설정 → 앱 서명」).
1. 약관 동의 → **앱 서명 키 변경** (또는 "기존 키 사용") → **Java 키 저장소에서 키 내보내기 및 업로드**.
2. 그 화면의 **pepk.jar** 와 **encryption_public_key.pem** 을 받아 이 폴더에 넣습니다.
   (화면이 `.pem` 대신 긴 16진수 문자열을 주면, 그 문자열을 `encryption-key.txt` 로 이 폴더에 저장.)
3. `pepk.cmd` 더블클릭 → 비밀번호를 두 번 물으면 `%USERPROFILE%\mybody-signing-key\KEY-INFO.txt` 의 값.
4. 만들어진 `mybody-pepk.zip` 을 화면에 올리고 저장.
5. 페이지의 앱 서명 키 SHA-256 이 **06d945a3 83797 1cea7 af0c0 3bcef f3139 64f57 7bc8c 16a41 033aa 2601 783de11** 인지 확인.
   다르면 구글 열쇠가 걸린 것 — AAB 올리기 전에 다시 「앱 서명 키 변경」.

왜 하나: 안 하면 구글이 새 열쇠를 만들어서, 플레이 판이 지금 친구들 폰의 앱과 **다른 앱**이 됩니다(지웠다 다시 깔아야 함).

## 3. 앱 콘텐츠 (20분)
왼쪽 「정책 및 프로그램 → **앱 콘텐츠**」. `앱-콘텐츠.md` 를 열어 놓고 위에서부터.
심사용 계정 칸은 `계정.txt`.

## 4. 스토어 등록정보 (10분)
왼쪽 「스토어 등록정보 → 기본 스토어 등록정보」. `등록정보.md` 를 붙여 넣고 `그림/` 을 올립니다.
「스토어 설정」에서 카테고리 **건강/운동**, 연락처 이메일.

## 5. 내부 테스트에 올리기 (5분 + 검토 대기)
「테스트 및 출시 → 테스트 → **내부 테스트**」
- 테스터 탭 → 이메일 목록 만들기 → 본인 Google 계정 → 저장
- 버전 탭 → 새 버전 만들기 → `mybody-v0.2.4-playstore.aab` 올리기 → 출시명 그대로 → 출시 노트(`등록정보.md` 끝) → 저장 → 버전 검토 → 내부 테스트 시작
- 첫 출시라 **검토**가 붙습니다(몇 시간~며칠). 대시보드에 남은 항목이 있으면 그것부터.

## 6. 비공개 테스트 → 친구들 (검토 끝난 뒤 5분)
「테스트 → **비공개 테스트**」 → 트랙 관리 → 테스터 탭 → 이메일 목록(친구들의 **폰 Google 계정**) → 국가/지역 대한민국 →
버전 탭 → 「내부 테스트에서 버전 추가」 → 출시. 게시되면 테스터 탭의 **참여 링크**를 친구들에게.
지금 깔린 APK 위에 업데이트로 깔립니다.

## 7. (정식 출시를 원할 때만)
비공개 테스트에 **12명 이상 · 14일 연속** 참여 → 대시보드 「프로덕션 액세스 신청」 → 승인 → 프로덕션 트랙에 승격.
친구들끼리만 쓸 거면 6번에서 끝입니다.

## 막히면
- "앱 번들이 잘못된 키로 서명됨": 2번을 안 했거나 구글 열쇠로 됐습니다. 2번 5항 확인.
- "versionCode 가 이미 사용됨": 더 최근 커밋의 AAB 를 쓰세요(릴리스 페이지 최신).
- 심사 반려 "로그인 불가": 노트북 서버와 터널이 꺼져 있었던 것. 켜고 재제출.
- 심사 반려 "개인정보처리방침": Pages 주소가 안 열리는지 폰 브라우저로 확인.
